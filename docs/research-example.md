# A concrete research request

Use this after installing Research. Standalone Codex invocation:

```text
$giasip-research Compare VHS and asciinema + agg for demonstrating an open-source CLI. Use official sources. Explain which outputs each supports, what the viewer needs, and what I would still need to test on my machine. Save the result as report.md.
```

For the namespaced Codex plugin, replace `$giasip-research` with `$giasip:research`. In Claude Code, use the invocation associated with your installation mode in the README.

## What to inspect in the report

This is an **illustrative outline**, not a captured run or a benchmark:

1. A short recommendation tied to the requested use case.
2. A comparison of the named tools, with official source URLs next to factual claims.
3. Installation or platform limitations, distinguished from what the agent actually tested.
4. A final **To verify** section for missing evidence and local checks.

The exact findings and recommendation depend on the available sources. Research does not guarantee exhaustive coverage or automatically validate every claim.

## Try it, then report a specific issue

Could you follow a source link? Did the report distinguish documented support from tested behavior? Was an important tool or limitation missing? Those are useful details to include in an issue; a private input or full chat transcript is not needed.
